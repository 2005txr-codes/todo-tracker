# To-do tracker

A small, dependency-free to-do app. Add tasks with optional due dates, check them off, filter by status, and clear what's done. Tasks are saved in your browser with `localStorage`, so they're still there when you come back.

## Run it

Open `index.html` in a browser. No build step or install needed.

**[Live demo](https://2005txr-codes.github.io/todo-tracker/)**

## Host it free with GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then save.
4. Your app will be live at `https://<your-username>.github.io/<repo-name>/` in a minute or two.
